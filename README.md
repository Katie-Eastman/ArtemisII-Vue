## About this Project: 
This project is a simple quiz site built using both Vue.js and Bootstrap. It is not meant to be expansive, but rather it is meant to demonstrate an understanding of Vue for the purposes of the final exam in my Intermediate Webdev class. All photographs used on the site are under NASA's open-source policy.
